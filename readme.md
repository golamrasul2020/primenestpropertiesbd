# Estatein — Real Estate Properties Website (Bootstrap 5 Demo)

A premium, responsive real estate frontend built with HTML5, CSS3, Bootstrap 5.3,
vanilla JavaScript and Bootstrap Icons. All property, agent and statistic data is
**sample/demo content** meant to illustrate the design and functionality.

## 1. Running Locally

No build tools required.

1. Download/clone the project folder.
2. Open `index.html` directly in a browser, **or** (recommended) serve it with a
   simple local server to avoid any CORS/path issues:
   ```bash
   # Python 3
   python -m http.server 8000
   # then visit http://localhost:8000
